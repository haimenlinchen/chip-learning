# Q-A

放学习过程中的问题与答案（Q-A：问题与答案笔记；用于沉淀需要读 RTL 才能回答的问题），尤其是“文档没写、需要读 RTL（寄存器传输级，用寄存器与组合逻辑描述硬件的抽象层；用于芯片设计与仿真）才能回答”的问题。

建议命名：

```text
<Project>-<Question>.md
例：CoralNPU-why-vrob.md
    Vortex-why-l1-shared.md
```

每篇至少包含：

1. 问题；
2. 结论；
3. 证据（文件/行号/波形（waveform：信号随时间变化的记录；用于定位时序问题）/日志）；
4. 仍然不确定的点。

这些问题可以反向链接（backlink：从笔记指向引用它的笔记；用于建立知识关联）到对应的项目笔记或概念笔记。
