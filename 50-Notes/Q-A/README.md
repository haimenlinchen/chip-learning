# Q-A

放学习过程中的问题与答案，尤其是“文档没写、需要读 RTL 才能回答”的问题。

建议命名：

```text
<Project>-<Question>.md
例：CoralNPU-why-vrob.md
    Vortex-why-l1-shared.md
```

每篇至少包含：

1. 问题；
2. 结论；
3. 证据（文件/行号/波形/日志）；
4. 仍然不确定的点。

这些问题可以反向链接到对应的项目笔记或概念笔记。
